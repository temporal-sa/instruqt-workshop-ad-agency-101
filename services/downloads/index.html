Running it locally

You need two tools: uv and the temporal CLI (both: brew install uv temporal, or see the install docs). Then:

unzip temporal-python-workshop.zip && cd temporal-python-workshop && uv sync

Open README.md and start at exercise 1 — the commands are identical to the ones you ran here.

Note: the zip contains the pristine exercise files, not any edits you've made in this sandbox.
